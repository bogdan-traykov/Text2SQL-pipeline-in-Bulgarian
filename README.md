# Text2SQL-pipeline-in-Bulgarian

Text2SQL system that takes a natural language input in Bulgarian, generates a SQL query that answers the question, runs it in the database, and returns natural language response using the results from the generated query. 

pipeline.py requests a natural language query in bulgarian and returns the SQL query generated by the LLM, the SQL results after executing the query on the database and a comment generated by the LLM about the results. pipeline_test.py takes a JSON file with questions related to the database, the SQL query output that is supposed to be returned, and query used to get the true answer to the question. All parts of the pipeline are recorded in MLFLow server. Ollama is used for running local LLMs and MySQL is used for the database.

## How to use pipeline_test.py
Make sure the folder contains JSON files called “DatabasesQA.json” and “DatabasesQA_BG.json” with the following format:
```
{
    "database_name":{
        "questions":[
            {
                "question": "(question 1 here)" ,
                "true_answer": "(SQL output that answers the question here)" ,
                "example_query": "(The query used to get the true answer)"
            },
            {
                "question": "(question 2 here)" ,
                "true_answer": "(SQL output that answers the question here)" ,
                "example_query": "(The query used to get the true answer)"
            },
        ]
    },
    "database_name2": …

}
```
where “database_name” is the name of the SQL database. It contains an array of dictionaries called “questions” each of which includes the question, an example of SQL query answering the question and the result of said query.
### Run MLFlow server 
1.	Open a MLFlow server on port 5000 from the terminal by using mlflow ui --port 5000 (example)
2.	Open pipeline_test.py and set the constants to the desired values.
Example:
```
DB_HOST: str = "localhost" # SQL host
DB_PORT: str = "3307" # SQL port
DB_USER: str = "user" # SQL user
DB_PASSWORD: str = "password" # SQL password
DB_DATABASE: str = "cyberchase" # Database name
DB_TABLES: List[str] = ["episodes"] # Tables to use (NOT USED IN pipeline_test.py)
OLLAMA_HOST: str = "localhost:11434" # Ollama host
TEXT_TO_SQL_MODEL: str = "qwen2.5-coder" # LLM model name
BG_MODEL : str = "hf.co/INSAIT-Institute/BgGPT-Gemma-2-9B-IT-v1.0-GGUF:Q4_K_S" # LLM model for generation in bulgarian
MLFLOW_URI = "http://localhost:5000" # MLFlow server uri (only in pipeline_test.py)

BG = True # If the Bulgarian pipeline should be used or not
```

3.	Run the python script.
4.	Go to the MLFlow ui by going to localhost:5000 from the browser to check the results.
### MLFlow UI Guide
1.	After the python script starts a MLFlow experiment will be created with the following format: “{Database name} – {LLM model used}” or “(BG) {Database name} – {LLM model used}” if it uses the bulgarian pipeline.
2.	For each question in DatabasesQA_BG.json (or DatabasesQA.json if BG mode is disabled), MLFlow run with the name of the question will be created and stored in the experiment.
3.	The execution time, inputs and outputs, for each step of the LLM parts of the pipeline can be checked from the traces tab after clicking on the run.
